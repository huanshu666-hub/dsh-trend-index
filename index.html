趋势解剖

官方索引只收 npm 可安装的那一半，因为它要求每个 Git 版本配一个 40 位 commit SHA，而社区目录不记录 SHA。 本索引补上那一半，并给每个插件算出热度分——它不是一个数字，而是四股力量的合力。
这个页面把这四股力量拆开给你看。
